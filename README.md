# Nerdbook

A jazz study book in LaTeX. Tunes are written in number notation:
melody as scale degrees, chords as Roman numerals, both relative to the key.

## Build

```bash
./make.sh
```

Requires `pdflatex` (TeX Live) and Python 3. Produces:

| Output | Content |
|---|---|
| `main.pdf` | full book: notation legend + all tunes |
| `forms.pdf` | forms only |
| `patternbook.pdf` | all patterns, with guitar tabs |
| `songs/<tune>.pdf` | one stand-alone PDF per tune, with tabs and legend |
| `ireal/*.html` | iReal Pro charts and playlists (open on a device, tap the link) |
| `site/` | static website linking all of the above (GitHub Pages) |

The footer shows the version (number of commits, `+` if uncommitted changes) and build date.
On every push, a GitHub Action builds everything; on `main` it publishes the `latest` release
and the website on GitHub Pages (enable Pages with source "GitHub Actions" in the repo settings).

## Layout

```
tunes.tex            list of tunes (\tuneinclude{<name>})
tunes/<name>/        one folder per tune
  tune.tex           \tune{Title}{Authors}{Year}{Keys}{Form} + list of parts
  form.tex           the form grid
  study.tex  patterns.tex  practice.tex  history.tex  recordings.tex
  ireal.py           chords for iReal Pro + chosen iReal exercises
exercises/           shared exercises, picked per tune with \exercise{<id>}
patterns/            shared patterns, picked per tune with \pattern[bars]{<id>}
tools/               ireal.py (iReal), tabs.py (guitar tabs), site.py (website)
legend.tex           notation legend
jazzmacros.sty       all macros
```

## Adding a tune

1. Create `tunes/<name>/` with `tune.tex` and `form.tex` (copy an existing tune).
2. Add `\tuneinclude{<name>}` to `tunes.tex`.
3. Optional: other parts, and `ireal.py` for iReal Pro charts.
4. Optional: `tune.ly`, the tune in LilyPond (ordinary pitches, with `tonic`, `melody`
   and `harmony`; copy `tunes/rifftide/tune.ly`), and `\tunescore` in `tune.tex`.
   `make.sh` renders it as the **Tune** section: scale degrees with rhythm, chords as
   Roman numerals (`lilypond/`). Requires [LilyPond](https://lilypond.org) 2.24.

## Adding a pattern

Create `patterns/<id>.tex` starting with a group line, `% group: <group>` (the harmonic
context: `scales-arpeggios`, `ii-v-i-major`, `ii-v-i-minor`, `secondary-dominants`, `chromatic`, `one-chord`,
`riffs`; the list is in `tools/tabs.py`). In the pattern book, patterns are grouped by
this context and sorted alphabetically by title, with an alphabetical index at the end.
Then add a `patternbox` and one or more tab lines, e.g.
`\patterntab{4 6 1' 3' | 2' 7 5 4 | 3}` (`'` octave up, `,` octave down, `|` bar line;
reference key G, or `\patterntab[C]{...}`). The tab is generated by `make.sh`.

See `legend.tex` (or the Notation chapter) for all symbols.
